# v0.2.0 — 可复现的 Windows 构建环境

**状态：** Planned  
**唯一主要任务：** 建立能够从干净环境重复构建、测试和打包 v0.1.0 功能的 Windows x64 工具链。  
**前置版本：** v0.1.0

## 用户价值

任何开发者或 CI 环境都能按文档产生一致、可验证的软件包。

## 范围

### 范围内

- 固定 Visual Studio、Qt、CMake、Ninja 和 vcpkg 版本。
- Debug/Release Preset、CI、测试、部署和依赖复制。
- 生成依赖清单和许可证材料。
- 产生可启动的 Windows x64 ZIP 开发包。

### 范围外

- PDFium和 PDF 功能。
- 正式签名安装程序和自动更新。

## 实施步骤

- [ ] 固定工具链和 vcpkg baseline。
- [ ] 建立 CI 构建与测试。
- [ ] 增加 Qt 部署脚本。
- [ ] 生成 SBOM 和第三方许可证包。
- [ ] 验证干净 Windows 环境运行。

## 验收标准

- [ ] 干净环境按 README 可以构建。
- [ ] CI 的 Debug、Release 和测试通过。
- [ ] 发布包无需开发环境即可运行。
- [ ] 软件显示版本为 `0.2.0`。
- [ ] 依赖版本和许可证均已记录。

## 测试要求

- CI 构建、单元测试和启动冒烟测试。
- 无 Qt SDK 环境的部署包启动测试。

## 安全与隐私

- 构建日志和制品不包含密钥。
- 依赖下载来源和哈希可追踪。

## 风险与回滚

- 风险：Qt/vcpkg 构建耗时及缓存体积较大。
- 回滚：恢复至 `v0.1.0`。
