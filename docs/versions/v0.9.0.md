# v0.9.0 — AI 文档数据底座

**状态：** Planned  
**唯一主要任务：** 建立带页面坐标的文档分块和本地全文索引。  
**前置版本：** v0.8.0

## 用户价值

文档可以被快速检索，并为后续 AI 回答提供可定位的证据片段。

## 范围

- 文本块、章节路径、页码和坐标数据模型。
- SQLite 元数据与 FTS5 索引。
- 增量索引、取消、状态和错误展示。
- 范围外：向量检索和模型调用。

## 实施步骤

- [ ] 定义 `DocumentChunk` 和数据库 schema。
- [ ] 实现布局分析和分块。
- [ ] 实现 FTS5 索引与查询。
- [ ] 实现文档修订和索引失效。

## 验收标准

- [ ] 每个结果都可映射到正确页码和区域。
- [ ] 文档修改后受影响页面会重建索引。
- [ ] 索引任务可取消且不阻塞 UI。
- [ ] 软件显示版本为 `0.9.0`。

## 测试要求

- 标题、段落、列表、表格、跨页段落和无文本页面。

## 安全与隐私

- 索引默认仅本地保存，并可由用户彻底清除。

## 风险与回滚

- 风险：错误分块降低后续问答质量。
- 回滚：恢复至 `v0.8.0` 并删除索引工作区。
