# v1.0.0 — Windows x64 正式发布

**状态：** Planned  
**唯一主要任务：** 发布满足产品、质量、安全、隐私和许可证要求的首个 Windows x64 正式版本。  
**前置版本：** v0.15.0

## 用户价值

用户获得可安装、可更新、具有 PDF 阅读编辑基础和可验证 AI 助手的正式产品。

## 范围

- 正式安装包、代码签名、发布说明和卸载流程。
- 稳定更新通道、制品校验和回滚说明。
- 用户文档、隐私说明及第三方许可证。
- 范围外：新增功能和其他操作系统。

## 实施步骤

- [ ] 冻结代码和依赖。
- [ ] 完成发布候选验收。
- [ ] 生成、签名和验证安装包。
- [ ] 发布文档、哈希、SBOM 和许可证材料。
- [ ] 创建 `v1.0.0` 标签。

## 验收标准

- [ ] 干净 Windows 10/11 x64 安装、升级和卸载成功。
- [ ] 所有 1.0 发布门禁通过。
- [ ] 制品签名和哈希验证成功。
- [ ] 软件及安装包显示版本为 `1.0.0`。
- [ ] 已发布用户、隐私和许可证文档。

## 测试要求

- 全量回归、安装升级、离线运行、恢复和发布制品验证。

## 安全与隐私

- 发布包签名；更新元数据和下载制品必须验证完整性。

## 风险与回滚

- 风险：签名、部署或更新渠道问题影响发布。
- 回滚：撤回制品并恢复至已验证的 `v0.15.0` 发布候选。
