# v0.11.0 — 可验证文档问答

**状态：** Planned  
**唯一主要任务：** 实现关键词与向量混合检索、引用验证及点击定位。  
**前置版本：** v0.10.0

## 用户价值

用户能针对整份文档提问，并通过页码和高亮原文核验答案。

## 范围

- Embedding Provider、向量索引和混合检索。
- 重排序、上下文构建和引用协议。
- 引用验证、跳转和高亮。
- 范围外：多文档知识库和自动编辑。

## 实施步骤

- [ ] 接入嵌入模型和向量存储。
- [ ] 实现 FTS5 与向量结果融合。
- [ ] 建立引用约束和验证器。
- [ ] 建立固定问答评测集。

## 验收标准

- [ ] 每个文档事实回答包含有效引用。
- [ ] 点击引用可定位到正确页面区域。
- [ ] 无充分证据时明确拒答。
- [ ] 软件显示版本为 `0.11.0`。

## 测试要求

- 数字、条款、跨页问题、无答案问题和伪造引用。

## 安全与隐私

- 模型引用只能指向实际提供的上下文块。

## 风险与回滚

- 风险：检索召回和模型引用并不天然可靠。
- 回滚：恢复至 `v0.10.0`，保留关键词搜索。
