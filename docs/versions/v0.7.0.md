# v0.7.0 — 基础批注

**状态：** Planned  
**唯一主要任务：** 实现基础批注的创建、修改、删除以及撤销重做。  
**前置版本：** v0.6.0

## 用户价值

用户可以用高亮、文本备注、图形和墨迹标记文档，并安全撤销操作。

## 范围

- 高亮、下划线、删除线、文本备注、矩形和墨迹。
- 属性面板、命令模型和撤销重做。
- 范围外：协作批注和高级图章。

## 实施步骤

- [ ] 定义批注领域模型和命令。
- [ ] 实现交互工具与属性面板。
- [ ] 接入统一撤销栈。
- [ ] 验证重新打开后的兼容性。

## 验收标准

- [ ] 所列批注可以创建、编辑和删除。
- [ ] 每项操作都可以撤销和重做。
- [ ] 保存后由常见阅读器正确显示。
- [ ] 软件显示版本为 `0.7.0`。

## 测试要求

- 页面旋转、缩放、跨页操作和反复撤销重做。

## 安全与隐私

- 批注富文本不得执行脚本或外部内容。

## 风险与回滚

- 风险：不同阅读器的批注外观兼容性不一致。
- 回滚：恢复至 `v0.6.0`。
