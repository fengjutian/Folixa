# v0.3.0 — PDFium 最小阅读闭环

**状态：** Planned  
**唯一主要任务：** 使用 PDFium 打开本地 PDF 并在 Qt 中正确显示首页。  
**前置版本：** v0.2.0

## 用户价值

用户可以选择一个 PDF，并看到清晰、比例正确的第一页。

## 范围

### 范围内

- 固定 PDFium revision 和许可证材料。
- `PdfiumAdapter`、文档句柄和页面句柄生命周期。
- 文件选择、密码回调、首页渲染和错误展示。
- 高 DPI 下的基础缩放。

### 范围外

- 连续滚动、多页缓存、搜索和编辑。

## 实施步骤

- [ ] 接入并封装 PDFium。
- [ ] 建立文档和页面 RAII 类型。
- [ ] 渲染首页到 Qt 图像。
- [ ] 增加错误和密码处理。
- [ ] 建立最小合法测试 PDF 集。

## 验收标准

- [ ] 可打开普通和密码保护 PDF。
- [ ] 首页方向、尺寸和颜色正确。
- [ ] 错误文件不会导致崩溃。
- [ ] 软件显示版本为 `0.3.0`。
- [ ] 自动化和渲染黄金图测试通过。

## 测试要求

- 普通、加密、空页、旋转页、损坏 PDF。
- 100%、150%、200% DPI 渲染检查。

## 安全与隐私

- 限制文件大小和页面尺寸。
- 不执行 PDF JavaScript 或附件。

## 风险与回滚

- 风险：PDFium 构建与 ABI 管理复杂。
- 回滚：恢复至 `v0.2.0`。
