# v0.8.0 — 页面管理与安全保存

**状态：** Planned  
**唯一主要任务：** 实现页面增删、旋转、重排和不会破坏原文件的保存流程。  
**前置版本：** v0.7.0

## 用户价值

用户可以整理 PDF 页面，并在失败时保留原始文档。

## 范围

- 页面插入、删除、旋转、拖拽重排。
- 临时文件写入、重新打开校验和原子替换。
- 自动恢复日志和另存为。
- 范围外：内容流文字编辑和数字签名。

## 实施步骤

- [ ] 定义页面操作命令。
- [ ] 实现安全写入流程。
- [ ] 实现恢复日志。
- [ ] 验证跨阅读器兼容性。

## 验收标准

- [ ] 页面操作正确并可撤销。
- [ ] 保存失败不会覆盖原文件。
- [ ] 崩溃后能发现并恢复未保存工作。
- [ ] 软件显示版本为 `0.8.0`。

## 测试要求

- 磁盘不足、只读文件、占用文件、网络盘中断和崩溃注入。

## 安全与隐私

- 恢复文件采用受控权限并支持清除。

## 风险与回滚

- 风险：页面操作可能影响对象引用和已有签名。
- 回滚：恢复至 `v0.7.0`，使用另存副本策略。
