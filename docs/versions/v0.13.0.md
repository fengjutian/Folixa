# v0.13.0 — OCR 与扫描件问答

**状态：** Planned  
**唯一主要任务：** 对无可用文本层的扫描 PDF 执行 OCR，并纳入检索和问答。  
**前置版本：** v0.12.0

## 用户价值

扫描合同、票据和历史文档也可以搜索、复制和进行带引用问答。

## 范围

- 本地 OCR Worker、语言包管理和置信度。
- OCR 文本、坐标和索引集成。
- 手动与自动触发策略。
- 范围外：直接重写 PDF 隐藏文本层。

## 实施步骤

- [ ] 建立 OCR Provider 和隔离 Worker。
- [ ] 实现页面图像预处理。
- [ ] 映射 OCR 结果至页面坐标。
- [ ] 集成索引、选择和问答。

## 验收标准

- [ ] 无文本扫描件可以搜索和问答。
- [ ] OCR 引用能定位到正确页面区域。
- [ ] OCR 可取消且有资源限制。
- [ ] 软件显示版本为 `0.13.0`。

## 测试要求

- 中英文、倾斜、低分辨率、混排和大批量扫描页。

## 安全与隐私

- OCR 默认本地执行；语言包来源及许可证可追踪。

## 风险与回滚

- 风险：识别误差可能被模型放大。
- 回滚：恢复至 `v0.12.0` 并删除 OCR 索引。
