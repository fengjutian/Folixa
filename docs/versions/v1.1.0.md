# v1.1.0 — 阅读与检索补齐

**状态：** Planned  
**唯一主要任务：** 把阅读器该有的浏览与查找能力补齐到与福昕同水平（对标项 A4/A5/A6/B6/B7）。  
**前置版本：** v1.0.0

## 用户价值

用户可以用习惯的方式读文档：单页、双页对开、全屏放映；搜索能区分大小写与整词，能来回跳转，不用记页码。

## 范围

### 范围内

- 布局模式：连续滚动（现状）、单页、双页对开、双页封面。
- 放映：全屏、逐页/逐行、Esc 退出、适配屏幕。
- 检索选项：区分大小写、全字匹配、正则、页范围。
- 前进/后退历史；按标签页独立。
- 缩放记忆：按文档记住缩放模式与比例。

### 范围外

- 文本重排（reflow）：明确不做，理由见对标基线 A8。
- 多窗口并排、分屏对照。

## 设计决策

### 布局模式是一个"页序号 → 视口锚点"的函数，不是四套代码

现有 `PageLayout` 已经能从滚动位置算出可见页与偏移。新增布局只允许扩展这个映射，不允许在 `PdfView` 里写 `if (mode == 双页)` 式的分支——否则缩略图、搜索结果、链接跳转三处都要跟着改，必然漏一处。

约定：任何"跳到第 N 页"的请求都先转成 `(pageIndex, 页内偏移)` 的锚点，再由当前布局换算成滚动值。

### 检索选项要能映射回字符框，否则等于没做

正则匹配最容易写错的地方不是匹配，是**把匹配的字节区间映射回 `TextPage` 的字符框**。`TextController` 的匹配结果必须带 `[startChar, endChar)` 的字符索引，高亮与跳转都只认这个索引；不允许在渲染层重新跑一遍匹配。

### 前进后退存的是视图状态，不是页号

历史项记录 `(pageIndex, zoomMode, zoomFactor, scrollAnchor)`。只存页号的话，用户在同一页里缩放平移之后按后退会"没反应"。

## 实施步骤

- [ ] 布局：`LayoutMode` 枚举 + `PageLayout` 扩展，缩略图/搜索/链接跳转统一走锚点换算。
- [ ] 放映：全屏容器、翻页键位、页数指示、退出恢复原布局。
- [ ] 检索：`SearchOptions` 结构（大小写、全字、正则、页范围），结果带字符索引。
- [ ] 历史：视图状态栈，容量 50，按标签页隔离，Alt+←/→ 绑定。
- [ ] 缩放记忆：按文档指纹存设置；"适应宽度"作为模式在窗口 resize 时重算。
- [ ] 界面验收脚本 `scripts/verify-reading.ps1`。

## 验收标准

- [ ] 四种布局切换后，页码指示、缩略图选中、搜索跳转三处一致。
- [ ] 放映下 Esc 退出并恢复原布局与缩放。
- [ ] 正则检索的命中区间与高亮框逐字符一致（含跨行匹配）。
- [ ] 后退 10 次再前进 10 次，视图状态与操作前一致。
- [ ] 重开文档后缩放模式保持；窗口 resize 时适应宽度仍然正确。
- [ ] Debug 和 Release 构建成功。
- [ ] 自动化测试通过。
- [ ] 软件版本号与本文档一致。

## 测试要求

- 布局：1 页、2 页、奇数页、旋转页、不同页面尺寸混排。
- 检索：大小写、整词、正则元字符、跨行、跨页、零结果、超长文档取消。
- 历史：连续跳转、跳转后缩放、关闭标签页后栈不串台。

## 安全与隐私

- 正则表达式有灾难性回溯风险：匹配在后台线程执行并带超时（默认 2s/页），超时必须可取消，不许阻塞界面。

## 依赖与许可证

- 无新增依赖。

## 风险与回滚

- 风险：布局模式改动波及缩略图与搜索结果三处定位逻辑。
- 回滚：保留连续滚动为默认模式，布局切换可整体关闭；恢复至 `v1.0.0`。
