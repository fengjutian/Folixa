## 状态约束

- 同一时间只能有一个 `In Progress` 版本。
- 后续版本可以补充规划，但不得提前实现其产品功能。
- 版本完成后先进入 `Verification`，通过发布门禁后才能改为 `Released`。
- 插入补丁版本时，在对应版本下方增加一行，例如 `0.3.1`。
