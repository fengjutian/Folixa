# v0.6.0 — 阅读导航

**状态：** Planned  
**唯一主要任务：** 实现缩略图、书签、内部链接和稳定的页面导航。

用户可以快速理解文档结构并在页面、书签和链接之间导航。

- 前进/后退导航历史。
- 范围外：编辑书签和外部附件执行。
