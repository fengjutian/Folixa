# v0.4.0 — 连续页面与瓦片渲染

**状态：** Planned  
**唯一主要任务：** 实现支持长文档流畅浏览的连续页面视口和可取消瓦片渲染。  
**前置版本：** v0.3.0

## 用户价值

用户可以连续滚动、缩放并浏览多页 PDF，而不会因整本渲染造成明显卡顿或内存失控。

## 范围

- 当前视口瓦片渲染、邻页预取和 LRU 缓存。
- 缩放、旋转、适合宽度及适合页面。
- 渲染优先级、取消和内存上限。
- 范围外：文本选择、搜索和编辑。

## 实施步骤

- [ ] 建立页面布局和坐标转换服务。
- [ ] 建立有界渲染队列和瓦片缓存。
- [ ] 实现滚动、缩放和旋转。
- [ ] 增加性能指标和压力测试。

## 验收标准

- [ ] 500 页测试文件可连续浏览。
- [ ] 快速滚动不会无限积压任务。
- [ ] 缓存遵守配置的内存上限。
- [ ] 软件显示版本为 `0.4.0`。

## 测试要求

- 长文档、高分辨率页面、快速滚动和反复缩放。

## 安全与隐私

- 页面尺寸、渲染时间和缓存内存均有上限。

## 风险与回滚

- 风险：PDFium 线程约束和像素复制影响性能。
- 回滚：恢复至 `v0.3.0`。
