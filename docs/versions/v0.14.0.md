# v0.14.0 — 受控 AI 文档操作

**状态：** Planned  
**唯一主要任务：** 允许 AI 生成文档操作提案，并在用户确认后通过命令系统执行。  
**前置版本：** v0.13.0

## 用户价值

用户可以使用自然语言完成空白页检测、页面整理和批注草稿，同时保留最终控制权。

## 范围

- 白名单只读工具和变更提案工具。
- JSON Schema 校验、影响预览和确认。
- 命令执行、撤销和审计。
- 范围外：无人确认的保存和任意代码执行。

## 实施步骤

- [ ] 建立 Tool Registry 和权限分类。
- [ ] 实现空白页及页面操作提案。
- [ ] 实现批注草稿。
- [ ] 实现差异预览、确认和审计。

## 验收标准

- [ ] AI 无法绕过确认执行变更。
- [ ] 工具参数均通过 schema 和文档修订校验。
- [ ] 所有变更可撤销并可审计。
- [ ] 软件显示版本为 `0.14.0`。

## 测试要求

- 越权工具、恶意参数、文档修订冲突和撤销恢复。

## 安全与隐私

- 不提供任意文件、Shell、下载或进程启动工具。

## 风险与回滚

- 风险：模型意图与用户预期不一致。
- 回滚：禁用变更工具，仅保留只读 AI，恢复至 `v0.13.0`。
