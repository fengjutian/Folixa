# v0.14.0 — 受控 AI 文档操作

**状态：** Released  
**发布标签：** `v0.14.0`  
**唯一主要任务：** 允许 AI 生成文档操作提案，并在用户确认后通过命令系统执行。  
**前置版本：** v0.13.0

## 用户价值

用户可以用自然语言完成空白页检测、页面整理和批注草稿，同时保留最终控制权。

## 范围

- 白名单只读工具和变更提案工具。
- JSON Schema 校验、影响预览和确认。
- 命令执行、撤销和审计。
- 范围外：无人确认的保存和任意代码执行。

## 设计决策

### 模型永远拿不到执行权

整条链路只有三段：**提案（模型）→ 校验（本地）→ 执行（用户确认后）**。
注册表里没有「执行」接口，这是故意的：想加一个能改文档的工具，
就必须同时写它的 schema 与预览文案，绕不过去。

### 三层拒绝，错误信息必须说清原因

| 情况 | 结果 |
|---|---|
| 未知工具（模型编的名字） | 拒绝：「未知工具」 |
| 明确禁止的工具（`shell.exec` / `file.write` / `net.*`） | 拒绝：「被禁止」 |
| 只读工具混进变更提案 | 拒绝：「只读工具不能出现在变更提案里」 |

为什么禁止名单要单列：模型可能从训练数据里「学会」调用 shell/file 这类名字。
若只是「查不到」，错误信息含糊；单列之后提示清楚，测试也能直接钉住。

### 多余参数一律拒绝，不静默忽略

模型给出未声明的参数，说明它在猜 schema。静默忽略会让用户以为
「按我说的执行了」，实际少了一半参数——宁可整条提案失败。

### 页码以当前文档为准，且带修订号

模型给的页码是「看起来的页码」，必须按页数校验（插入允许 `1..pageCount+1`）。
提案里可以带 `docRevision`：生成提案之后文档改过（用户删了页），
执行前必须重新生成——否则会作用在错误的对象上。

### 一次提案最多 20 条操作

防的是「模型一次要改一百页」这类误操作：数量本身就是风险信号，
超过上限直接判失败，让用户重新描述。

## 实施步骤

- [x] 建立 Tool Registry 和权限分类（`src/tools/ToolRegistry.{h,cpp}`）+ 提案校验
      （`src/tools/ProposalValidator.{h,cpp}`）+ 12 条单测。

## 验收标准

- [x] AI 无法绕过确认执行变更（注册表无执行接口，执行只在确认后）。
- [x] 工具参数均通过 schema 和文档修订校验。
- [x] 所有变更可撤销并可审计（统一撤销栈 + audit.jsonl）。
- [x] 软件显示版本为 `0.14.0`。

## 测试要求

- 越权工具、恶意参数、文档修订冲突和撤销恢复。

## 安全与隐私

- 不提供任意文件、Shell、下载或进程启动工具。
- 提案文本属于模型输出，和 v0.12.0 的材料一样按「不可信数据」处理。

## 风险与回滚

- 风险：模型意图与用户预期不一致。
- 回滚：禁用变更工具，仅保留只读 AI，恢复至 `v0.13.0`。

## 完成记录

**发布标签：** `v0.14.0`

### 交付内容

- `src/tools/ToolRegistry`：白名单工具 + 三种权限（只读 / 提案 / 禁止），**没有执行接口**。
- `src/tools/ProposalValidator`：schema 校验、页码范围、修订号、条数上限。
- `src/app/ProposalRunner`：提案 → 编辑命令（删页降序、页码 1 基转 0 基）。
- `src/app/EditProposalDialog`：逐条预览，默认按钮是「取消」。
- `src/app/BlankPageDetector`：按墨迹比例判空白页（渲染失败不算空白）。
- 主菜单「AI：找出空白页并提议删除」：扫描 → 提案 → 确认 → 命令 → 撤销栈。
- `ai::appendProposalAudit`：审计只记元数据（工具 / 条数 / 是否确认 / 结果）。
- `scripts/verify-proposals.ps1`：19 项断言，含「取消不改动」与「审计不含正文」。

### 验收与测试证据

- 单元测试：Debug/Release 各 32/32。
- 界面验收（CI，windows-2022）：十三项全部通过，含新增「AI 提案确认验收」。
- 实测：3 页样张（第 2 页空白）→ 扫描出 1 个空白页 → 取消无改动 →
  执行后页数 3→2 → Ctrl+Z 回到 3。
- CI：`windows-build` run `43598635699` success。

### 已知问题

- 提案只来自本地只读扫描（空白页），模型对话里生成提案还没接。
- 预览只列操作摘要，没有「改完之后长什么样」的页级差异。
- 一次只执行一类工具链（删除页），插入/移动/批注已有命令但还没有入口。
