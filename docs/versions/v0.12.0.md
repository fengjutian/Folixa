# v0.12.0 — AI 隐私与安全策略

**状态：** Planned  
**唯一主要任务：** 建立可执行的本地/云端数据策略和提示注入防护。  
**前置版本：** v0.11.0

## 用户价值

用户可以控制文档数据是否离开本机，并看到 AI 使用了哪些内容和权限。

## 范围

- 本地、片段云端和允许选定页面三种模式。
- Provider 数据策略、上传预览和审计记录。
- 间接提示注入、越权工具和外链防护。
- 范围外：企业集中策略服务器。

## 实施步骤

- [ ] 建立数据分类和策略引擎。
- [ ] 建立上传预览及用户设置。
- [ ] 增加提示注入评测集。
- [ ] 增加敏感日志检测。

## 验收标准

- [ ] 本地模式无文档内容外发。
- [ ] 云端请求可查看并符合选择的范围。
- [ ] 恶意文档文字不能扩大工具权限。
- [ ] 软件显示版本为 `0.12.0`。

## 测试要求

- 网络流量审计、提示注入、日志扫描和策略切换。

## 安全与隐私

- 本版本本身即安全与隐私门禁，阻断问题不得降级发布。

## 风险与回滚

- 风险：不同 Provider 数据政策可能变化。
- 回滚：全局禁用云端 Provider，恢复至 `v0.11.0`。
