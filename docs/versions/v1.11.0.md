# v1.11.0 — 内容编辑

**状态：** Planned  
**唯一主要任务：** 支持对已有页面内容的编辑：改文字、换图片、移动对象（对标项 E1–E5）。  
**前置版本：** v1.10.0

## 用户价值

用户不用回到原始文档就能改掉 PDF 里的错字、换掉一张图、把某个元素挪开——这是"阅读器"和"编辑器"的分界线。

## 范围

### 范围内

- 文本行编辑：改字、字号、颜色、字体（限已嵌入字体）。
- 段落重排：同一文本块内的行重排（受限于块识别）。
- 图像：替换、删除、缩放。
- 对象：选中、移动、删除、置顶/置底。
- 添加：矩形/椭圆/线条、文本框、超链接。
- 所有编辑进入统一撤销栈，支持字节级还原。

### 范围外

- 整篇自动重排（reflow）。
- 表格结构编辑、跨页段落重排。
- 解密后的内容重写（需先解密，属 1.6.0 能力）。
- 字体设计与完整字体嵌入（只做子集检查与降级提示）。

## 设计决策

### 编辑单位是"行"，不是"字符"

字符级编辑必然破坏字距：PDF 里一行文字是一串带定位的字形（`TJ` 数组 + 字距微调），删掉一个字不会让后面的字自动左移。正确做法是把整行读成"文本 + 字形位置 + 字体度量"，改完后**重新生成整行的 `TJ` 与定位**。

所以编辑模型是 `TextLine { text, origin, font, size, charWidths, matrix }`，不是"在字符串里替换一段"。

### 解析不完整就只读，不做猜测

内容流里可能有内联图像、表单 XObject、图案填充、裁剪路径嵌套。只要有一项解析不了，这一页就**只读**，并在界面标出原因。宁可少改，不可改坏——改坏的文件用户是拿不回去的。

### 字体缺字形时显式降级，不静默替换

改字时如果原字体子集里没有目标字形，有两种选择：换成别的字体（版式就变了）或拒绝。默认**拒绝并提示**，让用户明确选择"用替代字体"——静默替换会让用户以为改成功了，实际文件已经走样。

### 撤销存"字节差"，不存操作

文本编辑的重放很容易不一致（字体子集、对象编号都会变）。撤销栈里存的是该页编辑前后的对象字节（增量更新片段），撤销 = 写回旧字节。这样"撤销后与原文件逐字节一致"是可断言的。

### 这是唯一可能做不完的版本，必须先设止损点

内容流编辑是整条路线里最难的一块。v1.9.0 结束时做一次 go/no-go 评审：

- 若文本行模型与重写已跑通 → 按本版本范围推进；
- 若只跑通了"读结构" → 拆成 `1.11.0 结构分析（只读）`、`1.12.0 文本行编辑`、`1.13.0 对象编辑` 三个版本，不许硬塞进一个版本。

## 实施步骤

- [ ] 内容流 tokenizer 与操作符级解析（基于 qpdf 的解析能力）。
- [ ] 页面对象模型：文本行、图像、矢量图形、链接。
- [ ] 文本行重写：字距重算、矩阵变换、字体度量。
- [ ] 段落重排（块内）。
- [ ] 图像替换与对象移动。
- [ ] 添加图形/文本框/链接。
- [ ] 编辑命令接入统一撤销栈（字节差快照）。
- [ ] 编辑后自检：重新抽取文本、渲染比对、重叠检测。
- [ ] 验收脚本 `scripts/verify-edit.ps1`。

## 验收标准

- [ ] 改字后重新抽取，文本为修改后的内容，页内其他文字位置不变（±1pt）。
- [ ] 改字后无重叠、无溢出页面边界（自动检测并拒绝）。
- [ ] 换图后页面尺寸与其余元素不变，图像分辨率符合预期。
- [ ] 对象移动后坐标正确，另存并在福昕中打开位置一致。
- [ ] 撤销后该页对象字节与编辑前逐字节一致。
- [ ] 无法解析的页面进入只读并给出原因，不产生任何写入。
- [ ] Debug 和 Release 构建成功。
- [ ] 自动化测试通过。
- [ ] 软件版本号与本文档一致。

## 测试要求

- 文本：中文、英文、混排、竖排、旋转页、带字距调整的行、跨行段落。
- 字体：子集缺字形、Type0/CID 字体、未嵌入字体。
- 对象：表单 XObject 内的内容、图案填充、内联图像、嵌套裁剪。

## 安全与隐私

- 编辑只在本机进行，不调用任何模型；AI 发起的编辑走 0.14.0 的命令通道，需人工确认。
- 编辑失败必须保证原文件可恢复（沿用临时文件 + 重开校验 + 备份）。

## 依赖与许可证

- 使用 qpdf 的内容流解析能力，无新增第三方。

## 风险与回滚

- 风险：**这是全路线最高风险版本**——内容流重写可能产出"能打开但显示错乱"的文件，比打不开更难发现。
- 缓解：每次编辑后强制渲染比对 + 文本抽取自检；不通过就不落盘。
- 回滚：编辑功能可整体关闭（回到只读）；恢复至 `v1.10.0`。
