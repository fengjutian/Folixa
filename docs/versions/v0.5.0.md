# v0.5.0 — 文本选择与搜索

**状态：** In Progress  
**唯一主要任务：** 实现文本提取、鼠标选择、复制和文档内全文搜索。  
**前置版本：** v0.4.0

## 用户价值

用户可以查找、选择并复制 PDF 中的文本。

## 范围

- 字符、Unicode、坐标和阅读顺序提取。
- 鼠标命中、选区绘制和复制。
- 关键词搜索、结果列表、跳转和高亮。
- 范围外：OCR和语义搜索。

## 实施步骤

- [ ] 建立文本页缓存和坐标转换。
- [ ] 实现选区及复制。
- [ ] 实现后台全文搜索。
- [ ] 增加 CJK、RTL 和竖排测试。

## 验收标准

- [ ] 常见拉丁和 CJK 文档选择、复制正确。
- [ ] 搜索结果能跳转并高亮。
- [ ] 大文档搜索可取消且不阻塞 UI。
- [ ] 软件显示版本为 `0.5.0`。

## 测试要求

- 多语言、连字、旋转页、缺失 ToUnicode 和跨行选择。

## 安全与隐私

- 提取文本仅保存在本地受控缓存。

## 风险与回滚

- 风险：PDF 阅读顺序可能与视觉顺序不同。
- 回滚：恢复至 `v0.4.0`。
