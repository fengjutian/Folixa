# v1.4.0 — 批注互操作与审阅

**状态：** Delivered
**交付说明：** 能力已随 `v1.0.0` 一并交付，不单独创建 Git 标签。

**唯一主要任务：** 把批注类型、审阅流程与数据交换补齐到与福昕同水平（对标项 C1–C12）。  
**前置版本：** v1.3.0

## 用户价值

用户能用完整的批注工具做审阅——文本框、图章、箭头、云线、测量、附件——并且这些批注在别人的阅读器里长得一样；审阅意见可以回复、标记状态、导出给同事汇总。

## 范围

### 范围内

- 批注类型：波浪线、文本框/打字机、椭圆、线条、箭头、多边形、云线、图章（内置 + 自定义图片）、附件、声音、测量（距离/周长/面积 + 比例尺）。
- 墨迹橡皮与笔画编辑。
- 回复线程（`/IRT`）、审阅状态（`/State`）、作者与时间。
- XFDF / FDF 导入导出；批注摘要（HTML / PDF / 打印）。
- 批注属性面板：颜色、线宽、透明度、字体、锁定。

### 范围外

- 实时协同审阅、云端评论服务。
- 3D 批注、影视批注。

## 设计决策

### 类型扩展只改三处，不许出现第四处

新增一种批注要动的只有：`AnnotationType` 枚举、`annotationTypeToPdfium()` 映射、`AppearanceStreamBuilder` 的外观分支。属性编辑、撤销、面板列表、序列化都走既有泛化路径——一旦某个新类型需要"特殊处理"，说明抽象错了，先改抽象。

### 测量的正确性靠 `/Measure` 字典，不靠像素

距离/周长/面积的数值必须写进 `/Measure`（`/R` 比例、`/X` 单位、`/D` 显示格式），否则换个阅读器数值就没了。视觉上的标尺线是"外观"，数值是"数据"，两者都要写。

### 回复用标准线程，不用自定义 JSON

`/IRT` 指向父批注，`/RT /R` 表示回复。自定义结构在本程序里好看，导出到别人那里就成了一堆孤立批注。审阅状态用 `/State` + `/StateModel`（`Review`/`Marked`），同样为了互操作。

### XFDF 是坐标转换问题，不是格式问题

XFDF 的坐标是 PDF user space，颜色是 `#RRGGBB`，日期是 `D:YYYYMMDDHHmmSS`。坑在于：同一个批注在 CropBox ≠ MediaBox 的页面上，坐标基准不同。转换必须集中在 `AnnotationCodec` 一处，并且用"导出→导入→再导出"的往返测试守住。

### 摘要先做 HTML，不做排版引擎

批注摘要要能贴进邮件、能打印。做法是把批注列表渲染成一张 HTML 表（页、作者、类型、内容、截图缩略），再用已有的打印路径输出 PDF。不引入报表引擎。

## 实施步骤

- [x] 波浪线（Squiggly）：模型 / PDFium 映射 / 外观流 / 画布绘制 / 工具栏按钮；外观流与适配层各补一条测试。
- [x] 椭圆：以矩形为界拖出，外观流用四段贝塞尔近似，适配层走 `/Circle`。
- [x] 墨迹橡皮：`Tool::Eraser` 整笔删除（可撤销），命中判定抽成 `app/InkGeometry`（6 条几何单测）。
- [x] 线 / 箭头 / 多边形 / 云线：`/L`、`/LE`、`/Vertices`、`/BE` 由增量写入器的 `extraEntries` 补齐（PDFium 写不了字典项）。
- [x] 文本框：WinAnsi 外观 + `/DA`；中文由本程序画布绘制，其他阅读器按字体回退。
- [x] 图章：四种内置文字图章 + `/Name` 标准名。
- [x] 测量：距离 / 周长 / 面积三种口径 + `/Measure` 字典；`app/MeasureGeometry` 8 条几何单测。
- [x] 附件：写入器首次具备"新建对象"能力——EmbeddedFile 流 + Filespec + `/FS` 占位符替换；
      保存字节包含文件内容，并通过 qpdf 结构校验。
- [x] XFDF 导入导出：类型/坐标/颜色/正文/顶点/笔画/作者/状态/回复关系往返，9 条单测；菜单入口可用。
- [x] 回复线程与审阅状态的数据层：`/IRT` + `/RT /R`（父批注对象号由写入器按标记解析）、
      `/State` + `/StateModel /Review`、`/T` 作者（非 ASCII 走 UTF-16）、`/M` 时间；
      保存后重开能读回；批注面板已加「回复所选」「设置审阅状态」。
- [x] 附件文件名的 UTF-16 编码：`/UF` 一律 UTF-16BE，中文名不再乱码。
- [x] 属性面板：批注列表多选 + 颜色 / 线宽 / 不透明度，批量应用（每条一个撤销命令）；
      外观属性写进 `/BS /W` 与 `/CA`，外观流按批注自带值绘制（5 条单测）。
- [x] 批注摘要：`pdf/AnnotationSummary` 生成自包含 HTML（按页排序、正文转义），
      菜单提供「导出批注摘要（HTML）」与「打印批注摘要」（7 条单测）。
- [x] 图片图章：图片解码成 RGB 后压成 Image XObject，外观流用 `/Im0 Do` 绘制；带透明通道时额外写 `/SMask`（灰度蒙版），透明区不再变黑。
- [x] 录音：`app/AudioRecorder`（Win32 waveIn，16kHz/单声道/16bit，输出完整 WAV），菜单「录制声音批注…」；
      录到的 WAV 以附件形式随文档保存（PDFium 不能创建 `/Sound` 注释，原因见下）。
- [ ] 原生 `/Sound` 注释：需要把自建注释对象插进页面 `/Annots` 数组，属于"改页面对象"，
      当前增量写入器只支持重写批注对象本身。
- [x] 声音批注（有限实现）：WAV 解析成裸 PCM（6 条单测），随文档以附件形式保存。

- [x] 顺带修：写入器只写"页面里真实存在"的批注（模型里有、文档里没建出来的会被跳过，

## 测试要求

- 类型：旋转页、裁剪页、小页面（批注超出边界）、中文字体、自定义图章尺寸。
- 互操作：用福昕导出的 XFDF 导回来；用福昕加的批注我们能读能改。
- 压力：单页 500 条批注的渲染与面板性能。

## 安全与隐私

- 附件批注可以嵌入任意文件：导入时必须显示文件名、类型、大小并二次确认；不自动执行、不自动解压。
- 自定义图章图片只接受位图，限制尺寸与像素总量，防解码炸弹。

## 依赖与许可证

- 无新增第三方（XML 用 Qt 自带）。

## 风险与回滚

- 风险：批注类型增多导致面板与属性逻辑膨胀、互操作细节回归。
- 回滚：新类型可逐个关闭入口；数据格式向前兼容，旧版本仍能打开文档；恢复至 `v1.3.0`。
