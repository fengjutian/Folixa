# v1.6.0 — 安全写入与遮盖

**状态：** Planned  
**唯一主要任务：** 支持加密、权限、元数据清理与密文遮盖（对标项 G1–G4）。  
**前置版本：** v1.5.0

## 用户价值

用户可以把文档加密后发出、限制对方能否打印或复制、清除隐藏的作者与软件痕迹；需要保密的段落可以**真正删掉**，而不是画个黑框盖住。

## 范围

### 范围内

- 加密：AES-256（R6），用户密码与所有者密码分离。
- 权限位：打印、高质量打印、复制、批注、填写表单、提取、组装。
- 元数据清理：`/Info`、XMP、嵌入文件、`/PieceInfo`、脚本、隐藏图层。
- 密文遮盖（Redaction）：区域标记 → 内容流重写 → 图像像素覆盖 → 清理无引用对象。
- 遮盖预览与"不可恢复"验证。

### 范围外

- 证书加密（PKCS#7 信封）、DRM/权限服务器。
- 文档水印溯源（1.8.0 的水印是可见水印，不做隐写）。

## 设计决策

### 加密只能由写入层做

PDFium 只有 `FPDF_REMOVE_SECURITY`（去掉加密），没有"加上加密"的接口。加密必须由 qpdf 在写出时完成（`setR6EncryptionParameters`），并且**只能在全量重写模式下做**——增量更新无法给已有对象重新编码。

### 遮盖的正确性标准是"提取不出来"，不是"看不见"

画黑框是伪遮盖：文本还在，复制粘贴就能拿到。真正的遮盖必须：

1. 从页面内容流里**删除**与遮盖区域相交的文本/图形绘制操作符；
2. 图像区域用不透明矩形填充（不能只靠注释覆盖，注释可以被删掉）；
3. 删除不再被引用的对象（字体、图像 XObject）；
4. 清理文档级元数据与大纲里的泄露标题。

验收标准写成可执行断言：遮盖后重新抽取该页文本，**被遮字符串必须消失**；`strings` 扫全文件不得出现原文。

### 宁可多删，不可少删

内容流里判断"文字是否落在区域内"用到字形外框。外框与区域相交即视为命中（宁严勿宽）。代价是可能多删相邻字符——所以必须提供**遮盖预览**：先在同一位图上渲染删除后的结果，让用户确认再落盘。

### 权限位是"提示"，不是"强制"

PDF 的权限位是君子协定，任何开源库都能忽略。产品上不能宣称"加密后无法复制"。界面文案必须写"限制（可被专业工具绕过）"，并且**不把权限位当作访问控制手段**——真正的访问控制靠用户密码。

## 实施步骤

- [ ] 加密写入：R6 AES-256、两种密码、权限位映射。
- [ ] 打开时的权限识别与 UI 约束（禁止打印/复制时禁用对应入口）。
- [ ] 元数据清理清单与执行器。
- [ ] 遮盖：区域标记、内容流重写、图像覆盖、引用清理。
- [ ] 遮盖预览与不可恢复验证。
- [ ] 负例守卫：故意保留原文时验证必须变红。
- [ ] 验收脚本 `scripts/verify-security.ps1`。

## 验收标准

- [ ] 加密文件用福昕、Acrobat、本程序均可凭用户密码打开；无密码打不开。
- [ ] 权限位在福昕中按预期生效（禁止打印时打印入口灰掉）。
- [ ] 遮盖后提取文本不含被遮内容，全文件字符串扫描无原文。
- [ ] 遮盖后页数、页面尺寸、未遮盖区域渲染不变（像素比对）。
- [ ] 元数据清理后 `strings` 不再出现作者、软件名、原始路径。
- [ ] 清理/加密失败时原文件不变。
- [ ] Debug 和 Release 构建成功。
- [ ] 自动化测试通过。
- [ ] 软件版本号与本文档一致。

## 测试要求

- 加密：空密码、超长密码、中文密码、已有加密文档二次加密、破坏的加密字典。
- 遮盖：跨行文本、表格、扫描图像上的文字、旋转页、注释内的敏感内容。
- 清理：带嵌入字体子集名的文件（不能误删字体）、带附件的文件。

## 安全与隐私

- 本版本是安全门禁版本：遮盖不彻底属于**高严重度缺陷**，不得降级发布。
- 密码只在内存中短暂存在，不写日志、不进审计、不进恢复日志。
- 遮盖操作写审计日志（时间、页数、区域数），不记被遮内容。

## 依赖与许可证

- 使用 qpdf 的加密实现（已引入），无新增第三方。

## 风险与回滚

- 风险：内容流重写误删相邻内容；加密参数写错导致文件永久打不开。
- 回滚：遮盖与加密都是"另存为"操作，原文件不动；恢复至 `v1.5.0`。
