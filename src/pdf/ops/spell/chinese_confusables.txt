# 形近 / 音近 错字组（人工整理，非第三方词表拷贝）。
#
# 格式：一行一组，组内用空格分隔 2~4 个容易互相写错的字。
#   - 形近组：字形相近，读音往往不同（己/已/巳、末/未）。
#   - 音近组：读音相同或相近（的/地/得、在/再）。
#
# 判定口径（见 SpellChecker.cpp）：窗口里的字只有在本表里出现过，
# 且把该字换成本组里的另一个字之后整个窗口能对上词表，才算错字。
# 这样「自己」「已经」「未来」这些本身正确的词不会被误报。
#
# 整理口径：只收真实语料里常见的混淆对，不收生僻字的形近字。
# 行首 # 之后是注释，生成脚本会跳过。
