# Folixa 应用图标

## 概念：Prism Fold（折角即棱镜）

一张纸被折起一角。折角是整页里唯一"被翻开"的地方，也是 Prism 的棱镜面：

- **白纸**：文档本身，永远是主体。
- **蓝色底板**：Prism Blue 的工作空间。
- **紫色折角**：Intelligence Violet 的智能层，从纸角进入文档。

三个元素只讲一件事——文档被打开，也被理解。没有文字、没有闪光、没有第二个隐喻，
所以 16px 下退化成一个「白页 + 紫角」，仍然认得出是 Folixa。

## 几何与网格

| 项目 | 值（1024 设计网格） |
|---|---:|
| 底板 | 1024 × 1024，圆角 228（≈22%） |
| 纸张 | 468 × 684，圆角 46，居中偏左 |
| 折角 | 165（纸宽的 35%） |
| 文字线 | 粗 34，圆头，长度递减 |
| 投影 | dy 24 / 模糊 28 / 不透明度 34% |

纸面左移 28px，让投影和折角在右侧有呼吸空间；折角不贴边，避免小尺寸下和底板圆角打架。

## 颜色

全部取自 `docs/UI_DESIGN_SYSTEM.md`，不另造品牌色。

| 用途 | 色值 |
|---|---|
| 底板渐变 | `#5E80F5` → `#4A69E2` → `#3350BE`（prism.500 系） |
| 纸张 | `#FFFFFF` → `#E7EDFA` |
| 折角 | `#C9B7FB` → `#7B5CE0`（ai.300 → ai.600） |
| 文字线 | `#C9D5EE` |
| 投影 | `#0A1230` @ 34% |

## 尺寸行为

同一个几何在所有尺寸重新光栅化，不是把 1024 缩下去：

| 尺寸 | 处理 |
|---|---|
| 32–1024 | 完整：三条线、投影、底板高光 |
| 24 | 三条线减为两条，避免糊成灰块 |
| 16 | 只留一条线；折角保留（这是唯一的品牌识别点） |

## 产物与再生成

```text
assets/branding/
├─ build_icon.py            单一几何来源：SVG / PNG / ICO / 预览
├─ folixa-icon.svg          1024×1024 主矢量
├─ folixa-icon-<n>.png      16 / 24 / 32 / 48 / 64 / 128 / 256 / 512 / 1024
├─ folixa.ico               Windows 多尺寸（16–256，每帧独立渲染）
└─ folixa-icon-preview.png  浅色 / 深色背景尺寸对照
```

```powershell
python assets/branding/build_icon.py
```

改设计只改 `build_icon.py` 顶部的常量（`PAGE` / `FOLD` / `LINES` / 颜色），
重新跑一次，四类产物同时更新，不会出现 SVG 和 ICO 不是同一版的情况。

## 接入现状（待统一）

仓库里目前存在**两套互不相同的标记**：

| 位置 | 当前图形 |
|---|---|
| `assets/branding/folixa-icon.svg` | 折角文档（本设计），用于品牌资产与安装包 |
| `src/app/icons/app.svg` + `src/app/BrandMark.cpp` | 白页 + 四角星芒（欢迎页 / 窗口图标） |

`src/CMakeLists.txt` 已经把 `src/app/app.ico` 接到 Windows 版本资源，
`main.cpp` 用 `:/icons/app.svg` 设窗口图标——两处都指向星芒版，和品牌资产不一致。

统一到本设计需要改三处：

1. `src/app/icons/app.svg` ← 本目录的 `folixa-icon.svg`（`width/height` 改为 256，`viewBox` 保持 1024）。
2. `src/app/app.ico` ← 本目录的 `folixa.ico`。
3. `src/app/BrandMark.cpp` 的欢迎页自绘标记：把「白页 + 星芒」换成「白页 + 折角」。

## 使用规则

- 最小尺寸 16px。低于 16px 不要再用这个图标，改用文字。
- 不拉伸、不描边、不换色、不加外发光；底板自带 16% 白色描边高光，不要再叠。
- 深色背景直接使用，底板渐变在深色下仍有足够对比。
- 16px 下不要额外裁边——留白已经是按 16px 调过的。
